# Cotizador YuranSnacks

Mini aplicación web para calcular rápidamente cotizaciones de pedidos de YuranSnacks y preparar un resumen para enviar por WhatsApp.

## ¿Para qué sirve?

La aplicación permite calcular el precio de un pedido según:

* Producto seleccionado.
* Cantidad.
* Canal de entrega.

También permite copiar el resumen de la cotización para pegarlo directamente en WhatsApp.

## Productos

* Barra Kiwicha y Cacao — S/ 8
* Barra Quinua Original — S/ 7
* Pack x5 Kiwicha y Cacao — S/ 35
* Pack x5 Quinua Original — S/ 30

## Canales de entrega

* Recojo en punto de venta — sin costo adicional.
* Delivery en Lima — S/ 5 adicionales.

## Características

* Una sola página.
* Diseño adaptado para celular.
* No requiere registro de usuario.
* No utiliza base de datos.
* No requiere servidor backend.
* Los precios están definidos directamente en la aplicación.
* Permite copiar el resumen del pedido.

## Tecnologías

* HTML
* CSS
* JavaScript

No utiliza librerías externas.

## Uso

Abrir `index.html` en un navegador web.

También puede publicarse posteriormente mediante un servicio de hosting como Vercel.

## Proyecto

Este proyecto corresponde a una primera versión (MVP) del cotizador de YuranSnacks.
